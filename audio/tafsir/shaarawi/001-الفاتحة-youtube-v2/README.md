# خواطر سورة الفاتحة — الشيخ الشعراوي — v2

نسخة محلية تجريبية بصيغة الكتالوج الحالية: ٧ ملفات للآيات، و٨ موضوعات عامة. التشغيل الكامل يعيد استخدام ملفات الآيات والموضوعات نفسها دون ملفات تسجيل كامل إضافية.

## المصدر وسلامة الملفات

المصادر هي التسجيلات الخمسة المنسوبة إلى القناة الرسمية للشيخ الشعراوي، وروابطها وعناوينها محفوظة في manifest.json. ملفات التنزيل الأصلية لم تعد موجودة في مجلد downloads. استُخدمت نسخ التسجيلات الكاملة المحفوظة في مجلد v1 كمدخلات للقص؛ طابقت هذه النسخ بصمات الإصدار السابق، لكنها لا تطابق البصمات الأصلية المسجلة. لذلك تظل سلامة البايتات الأصلية قبل النقل غير قابلة للتحقق. تفاصيل النسخ محفوظة في source-recovery.json ضمن أدلة التحقق.

صيغة الصوت MP3 أحادية القناة ٦٤ كيلوبت/ثانية و٤٨ كيلوهرتز. جميع المقاطع نُسخت بإطارات MP3 دون إعادة ضغط. عناوين الموضوعات وصفية تحريرية وليست عناوين أصلية أو نصوصًا قرآنية.

## التشغيل الكامل

قائمة playlist.json زمنية وتعيد استخدام المقاطع الموجودة. ملف M3U8 يتضمن خيارات start/stop لبرنامج VLC؛ قد تتجاهلها مشغلات M3U العامة. مدة التشغيل 4.18 ساعة، وتتضمن المقدمات والخواتيم مرة واحدة.

## المراجعة

تمت مراجعة التفريغ العربي الكامل والسياق وتفريغات المقاطع الملتبسة، وحُفظت الحدود التحريرية في edit-v2.json. فحصت آلية التصدير سلامة MP3 وحدود التقسيم ومطابقة حزم التشغيل. المراجعة السمعية البشرية الدقيقة ما زالت معلقة؛ النسخة تجريبية. لا تعني نسبة المصدر منح ترخيص مستقل لإعادة نشر التسجيلات.
