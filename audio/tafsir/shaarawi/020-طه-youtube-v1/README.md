# خواطر طه — إصدار يوتيوب المقسم بالآيات

١٣٥ ملف آية و١٧ جزءًا للسورة كاملة. الشرح المتداخل لعدة آيات يحمل المجموعة نفسها كما في التقسيم السابق.

المصدر: https://www.youtube.com/playlist?list=PLD00D5CD36A48758F

الصوت بمستوى متوازن، مع نسخ إطارات MP3 عند التقسيم دون ضغط إضافي. فُك ترميز كل ملف كاملًا وفُحصت بصماته وتغطية المصادر.

بُنيت الحدود بمطابقة التسجيل القديم والجديد ومراجعة سياق التفريغ. لم تكتمل المراجعة السمعية البشرية لكامل المقاطع.

يتوفر فهرس الآيات في `manifest.json` وقائمة تشغيل الدروس الكاملة في [taha-full.m3u8](taha-full.m3u8).
