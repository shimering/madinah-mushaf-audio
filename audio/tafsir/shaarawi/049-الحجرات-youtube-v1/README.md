# خواطر سورة الحجرات — الشيخ الشعراوي

١٨ ملفًا للآيات، و٤ موضوعات عامة، و٥ دروس بالترتيب للتشغيل الكامل.
الآيتان ٤ و٥ تشتركان في شرح واحد؛ تمنع قائمة الاستكمال تكراره.
حفظت ملفات MP3 الموردة بترميزها: ٦٤ كيلوبت/ثانية، قناة واحدة، ٤٨ كيلوهرتز. القص بنسخ الإطارات دون إعادة ضغط.

## المصادر واكتمال التغطية

[القائمة الرسمية على يوتيوب](https://www.youtube.com/playlist?list=PL946DB972F94C447E) هي مصدر الملفات الموردة.
الملفان المورّدان 03 و04 يحملان اللقاء نفسه؛ أثبتت المقارنة الصوتية تطابقه مع فرق بداية ٤٫٤٤ ثانية. أدرج اللقاء مرة واحدة، وحفظت الأصول المحلية كاملة.
القائمة الرسمية الموردة تغيب عنها الحلقة بين شرح الآيتين ١١ و١٣، ولذلك استُكملت من [الحلقة الثالثة في أرشيف sharawe](https://www.youtube.com/watch?v=v741vFe6nw0).
حوّل صوت الحلقة المستعادة مرة واحدة إلى نفس تنسيق الملفات الموردة، ثم قص بنسخ الإطارات. قد يختلف طابع التسجيل عن بقية الدروس.
